# 汪曾祺 vs 李娟：用邏輯迴歸區分兩種「生活流」散文的作者

一個用於中文寫作課/人文計算課程的作者歸屬（authorship attribution）小專案。
問題：**給定一段散文，能否判斷它是汪曾祺寫的還是李娟寫的？**
兩位作家同屬「生活流」抒情散文傳統，題材相近（草木、飲食、勞作、家人），
但句子節奏、用詞習慣、口語偏好截然不同。這個任務與課堂上用邏輯迴歸做情感
分類的思路一致——只是把「正面/負面」換成了「作者 A/作者 B」，並讓模型的
每個預測都可以追問：它到底在看什麼？

## 研究問題

1. 對風格相近的兩位當代作家，字元 TF-IDF + 邏輯迴歸能把段落歸對的機率有多高？
2. 模型依賴的是**文體指紋**（虛詞、句法、標點習慣），還是**題材詞彙**（地名、名物）？
3. 對訓練資料之外的文字（史鐵生、劉亮程、AI 模仿文風），模型給出的
   「文風座標」意味著什麼？邊界在哪裡？

## 標籤定義

| 標籤 | 含義 | 判定標準 |
|------|------|----------|
| `汪曾祺` | 文字出自汪曾祺（1920–1997）已出版作品 | 正文段落，含其晚期散文的敘事與議論 |
| `李娟` | 文字出自李娟（1979– ）已出版作品 | 正文段落，非虛構敘事散文 |

文字單位：**自然段**（30–600 字）。超出 600 字的長段在句末切成 ≤500 字片段。
不使用標題、註文、腳註、編者按、轉載宣告。每一篇作品最多貢獻 40 段，
避免個別長文主導某類樣本。

## 方法概要

- **切分**：80/20，按「篇」分層切分（`train_test_split(..., stratify=作者,
  random_state=42)`）。同一篇的所有段落只進訓練集或只進測試集，
  避免同篇上下文洩漏；另生成按段落隨機切分的對照組以量化洩漏的影響。
- **特徵**：主方案為字元級 1–2 元 TF-IDF（`min_df=3`, `max_features=50000`,
  sublinear tf）；對照為 jieba 分詞後最高頻 200 詞的詞頻（作業提示的方案）、
  詞級 TF-IDF，以及僅 120 餘個功能詞的 z-score 詞頻（經典文體計量學做法）。
- **模型**：`sklearn.linear_model.LogisticRegression`（C=1.0，max_iter=2000）。
- **評估**：準確率、混淆矩陣、逐類精確率/召回率/F1。
- **應用**：對訓練資料之外的文字逐段輸出 P(李娟)，取均值得到「文風座標」。

## 主要結果（詳見 `report.md` / `output/`）

- 語料（平衡後）：每類 532 段，共 1,064 段；訓練 848 段、測試 216 段
  （以「篇」為單位 80/20 切分，種子 42）。
- 特徵選擇：僅用訓練集做 5 折**分組**交叉驗證（同樣按篇分組）——
  字元 TF-IDF 92.0%±1.7%、詞級 TF-IDF 91.9%±2.6%、200 高頻詞 86.0%±2.4%，
  選定字元 TF-IDF。
- 測試集：段落級準確率 **89.3%**，文章級（每篇多數投票）**92.7%**；
  23 個誤判全部落在 |P−0.5|<0.15 的邊界帶（無自信錯判）。
- 穩健性：遮蔽人名/地名後 **88.9%**（≈不變）→ 模型不靠專名作弊；
  僅 120 虛詞 z-score 達 **75.0%**；按段落隨機切分（有洩漏）95.3%。
- 應用：史鐵生 0.58 / 劉亮程 0.70 / AI 模仿汪曾祺 0.505（恰在邊界）/
  AI 模仿李娟 0.69（P(李娟)，全部落在中間地帶）。
